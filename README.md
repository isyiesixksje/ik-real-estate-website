# IK Real Estate Website

A responsive, dark luxury real estate website for **IK Real Estate**.

## Preview locally

Open `index.html` in your browser.

## GitHub Pages

1. Open the repository **Settings**.
2. Open **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose `main` and `/ (root)`.
5. Save.

The website will be published from `index.html`.
